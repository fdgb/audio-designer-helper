# CG / 视频音乐情绪分析模块（Music Emotion Analysis）

> 配套脚本：`scripts/music_emotion.py`
> 适用：审外包 CG / 过场动画的音乐情绪弧——"音乐的情绪转折点有没有卡上剪辑点""情绪对不对"。
> 场景触发词：音乐情绪、情绪分析、CG 音乐、视频音乐情绪、情绪时间线、mood analysis

---

## 0. 它产出什么

输入**视频**（自动抽音轨）或**音频** → 切成固定窗口（默认 8s）→ 每窗提取声学描述子 → 映射成 **valence(愉悦度)–arousal(激昂度)** 二维 + **离散情绪标签**，输出一张**情绪时间线**；全局再估一个 **tempo(BPM)** 和总体情绪。

每窗描述子：
- `mode`：大调/小调近似（chroma 与大小调模板相关，粗）
- `centroid`：频谱质心 / 明亮度（越低越闷，越高越亮）
- `tension`：频谱平坦度（越平 = 越噪/越紧张）
- `rms`：能量
- `valence/arousal`：由 mode + 明亮度 + 能量 启发式映射（0–1）
- `tag`：激昂/史诗、紧张/压迫、宁静/温暖、悲伤/低沉、欢快、神秘/中性

---

## 1. 用法

```bash
# 视频：自动抽音轨分析
python scripts/music_emotion.py "某CG.mp4" --win 8

# 音频文件
python scripts/music_emotion.py "某BGM.wav" --verbose

# 机器可读输出（交给 agent 做 narration / 比对）
python scripts/music_emotion.py "某CG.mp4" --json
```

- `--win`：窗口秒数（默认 8；短 CG 可降到 4–5 看更细的转折）
- `--verbose`：每窗打印 8 段频段条
- `--json`：输出结构化 JSON（时长 / BPM / 每窗 timeline）

---

## 2. 典型用途

1. 把外包 CG 音乐跑一遍 → 拿到情绪时间线；
2. 对照剪辑点时间码，看"该紧张的地方有没有紧张、该舒缓的有没有舒缓"；
3. 多版 CG 音乐横向比情绪弧；
4. 让 agent（LLM）把时间线 narration 成一份"音乐情绪表"给导演/外包方。

---

## 3. 诚实边界（务必照实传达）

- 分析的是**音乐自身的声学情绪**，不是画面的叙事情绪——镜头悲喜它不知道。
- 若视频里**人声/音效与音乐混在一起**，会污染特征 → 最好喂**纯音乐轨**或音乐占比高的段。
- **没有训练好的"情绪分类模型"**（那要从 zenodo 下权重，本环境被限速），所以标签是**粗粒度启发式**，用作"找情绪错位/核对情绪弧"足够，不是精确心理学量表。
- `tempo` 与 `mode` 是**近似**（自相关 / chroma 相关），不是专业打谱结果。

## 4. 已知坑 / 注意事项

| 现象 | 原因 | 处理 |
|------|------|------|
| `需要 numpy` | 环境没装 numpy | `pip install numpy` |
| 视频分析慢 | 先 ffmpeg 抽音轨 + 逐窗 FFT | 正常；长视频可先截片段 |
| 情绪标签"反了" | 混音有人声/音效污染 | 喂纯音乐轨重跑 |
| tempo 估得怪 | 无稳定节拍（氛围/环境乐） | 忽略该项，只看情绪弧 |
